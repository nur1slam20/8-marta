Открой `index.html` в браузере или задеплой на GitHub Pages.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на [github.com/new](https://github.com/new) (например, название `8march` или `jasmina`).
2. **Не** добавляй README, .gitignore и лицензию — они уже есть локально.
3. В папке проекта выполни (подставь свой логин и имя репозитория):

```bash
cd "/Users/nurislam/Desktop/Жасмина"
git remote add origin https://github.com/ТВОЙ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git branch -M main
git push -u origin main
```

4. В репозитории на GitHub: **Settings → Pages → Source**: выбери ветку **main**, папку **/ (root)** → Save.
5. Через пару минут сайт будет по адресу: `https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`
